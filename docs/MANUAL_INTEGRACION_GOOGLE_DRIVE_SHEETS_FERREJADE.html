💡 Resumen Ejecutivo: Este microservicio gratuito convierte tu cuenta oficial de Gmail (ferrejadepzo@gmail.com) en un potente servidor en la nube sin pagar membresías ni bases de datos costosas. Cada vez que tomas una foto a un empaque con el Escáner IA Móvil, la fotografía se guarda automáticamente en una carpeta de tu Google Drive y los 15 datos maestros del producto se asientan en una fila de tu Google Sheet en tiempo real.

🏛️ 1. Arquitectura y Flujo de Datos en Tiempo Real

El sistema opera bajo un flujo automatizado de 4 etapas que no requiere instalar ningún programa en tu computadora:

  • Paso A (Captura & Visión IA): Apuntas la cámara del teléfono o PC a la caja física. El modelo Gemini Vision extrae el nombre, marca, medidas, categoría, código de barras y sugiere precio de venta con margen del 35%.
  • Paso B (Envío Cifrado): La aplicación empaqueta la información y la fotografía comprimida en alta definición.
  • Paso C (Google Apps Script Microservice): El script recibe la carga, decodifica la imagen en el Google Drive de FerreJade y genera un enlace web público permanente.
  • Paso D (Asiento Contable en Google Sheets): Registra el producto con fecha, precio en USD, precio convertido a Bolívares con la tasa oficial BCV y el hipervínculo directo a la fotografía.

🚀 3. Tutorial Paso a Paso: Instalación en Google Drive (Solo 3 Minutos)

Paso 1: Abrir Google Drive y Crear la Hoja de Cálculo

  1. Abre tu navegador de internet (Chrome o Edge) e ingresa a https://drive.google.com.
  2. Asegúrate de haber iniciado sesión con el correo oficial: ferrejadepzo@gmail.com.
  3. Haz clic en el botón superior izquierdo "+ Nuevo" y selecciona "Hojas de cálculo de Google" (Hoja en blanco).
  4. En la esquina superior izquierda, haz clic en "Hoja de cálculo sin título" y cámbiale el nombre a:
    FerreJade - Catálogo Maestro

Paso 2: Abrir el Editor de Apps Script

  1. En el menú superior de la hoja de cálculo, haz clic en Extensiones.
  2. En el menú desplegable, haz clic en Apps Script.
  3. Se abrirá una nueva pestaña con el editor de código de Google. Verás unas líneas que dicen function myFunction() { }.
  4. Borra todo ese texto para que el editor quede completamente en blanco.

Paso 3: Pegar el Código del Conector y Guardar

  1. Copia todo el código que se encuentra en la Sección 5 de este manual (o del archivo docs/GOOGLE_APPS_SCRIPT_DRIVE_CONNECTOR.js).
  2. Pégalo en el editor de Apps Script.
  3. Haz clic en el icono del disquete "Guardar proyecto" (o presiona Ctrl + S).
  4. Opcional: En la esquina superior izquierda, haz clic en "Proyecto sin título" y nómbralo Conector FerreJade Cloud.

Paso 4: Implementar como Aplicación Web (¡Punto Crítico!)

  1. En la parte superior derecha de Apps Script, haz clic en el botón azul "Implementar" (Deploy).
  2. Selecciona la opción "Nueva implementación".
  3. A la izquierda, haz clic en el icono de engranaje (⚙️) junto a "Seleccionar tipo" y elige "Aplicación web".
  4. Rellena los campos exactamente como sigue:
    • Descripción: Conector FerreJade v1.0
    • Ejecutar como: Yo (ferrejadepzo@gmail.com)
    • Quién tiene acceso: Cualquier persona (Anyone - Crucial para que el celular pueda enviar datos)
  5. Haz clic en el botón "Implementar".
⚠️ Autorización de Permisos de Google (Solo la primera vez):
Google te mostrará una ventana pidiendo autorización para que el script acceda a Google Drive y Sheets:
  1. Haz clic en "Revisar permisos" (Review permissions) y selecciona tu cuenta ferrejadepzo@gmail.com.
  2. Aparecerá un aviso que dice "Google no ha verificado esta app". No te preocupes, esto ocurre porque es un script privado creado por ti mismo.
  3. Haz clic en el texto pequeño abajo a la izquierda: "Configuración avanzada" (Advanced).
  4. Haz clic en "Ir a Conector FerreJade (no seguro)".
  5. En la última pantalla, haz clic en "Permitir" (Allow).

Paso 5: Copiar la URL del Webhook

  1. Google te mostrará una ventana con el mensaje "Implementación actualizada".
  2. Bajo el título "URL de la aplicación web" verás un enlace largo que termina en /exec:
    https://script.google.com/macros/s/AKfycb.../exec
  3. Haz clic en el botón "Copiar" junto a la URL. ¡Ya tienes tu enlace listo!

📲 4. Vincular el Webhook en el Sistema FerreMax / FerreJade

Una vez que copiaste la URL del Webhook, vincularla al sistema es automático y toma 30 segundos:

  1. Abre tu aplicación FerreMax / FerreJade en el navegador o en tu celular.
  2. Ingresa al Panel Administrativo (o a la sección de Inventario).
  3. Haz clic en el botón verde con icono de nube: "☁️ Google Drive & Sheets".
  4. Se abrirá el modal de sincronización oficial.
  5. En el campo "URL del Webhook de Google Apps Script", pega el enlace copiado (el que termina en /exec).
  6. Asegúrate de que la casilla "☑ Sincronizar automáticamente al escanear cada producto" esté marcada.
  7. Haz clic en "💾 Guardar Configuración". Verás una notificación verde: "Configuración guardada correctamente".
  8. Haz clic en "🧪 Probar Conexión". El sistema enviará una señal a tu script y mostrará:
    🟢 Conexión exitosa con Google Cloud / ferrejadepzo@gmail.com
  9. (Opcional): Haz clic en el botón "☁️ Enviar Todo el Catálogo a Google Sheets". El sistema enviará todos los productos existentes a la hoja de cálculo de inmediato.

🧪 5. Fase de Pruebas: Cómo Eliminar Productos de Prueba y Limpiar SKUs

Cuando hagas tus primeros escaneos para probar la cámara y la inteligencia artificial, se crearán registros de prueba. Para dejarlos limpios antes de comenzar con el inventario real de la tienda física, sigue este procedimiento de 1 minuto:

A. Limpiar Productos de Prueba en Google Sheets:

  • Abre tu hoja de cálculo "FerreJade - Catálogo Maestro" en Google Drive.
  • Haz clic en los números de las filas que quieras borrar (por ejemplo, las filas 2, 3, 4...).
  • Haz clic derecho sobre los números seleccionados y elige "Eliminar filas seleccionadas".
  • La fila de encabezados dorados (#1) se mantiene intacta y la hoja queda lista para los productos reales.

B. Limpiar Fotos de Prueba en Google Drive:

  • En tu Google Drive, abre la carpeta creada automáticamente llamada "FerreJade - Fotos de Productos".
  • Selecciona las fotos de prueba y arrástralas a la Papelera (o presiona la tecla Suprimir).

C. Limpiar o Modificar Productos y SKUs en FerreMax:

  • Para borrar un producto individual: En el módulo de Inventario de FerreMax, localiza el producto de prueba y haz clic en el icono rojo de papelera 🗑️.
  • Para corregir un SKU o nombre: Haz clic en "Editar" en cualquier producto. Puedes escribir el SKU oficial que use tu negocio (por ejemplo HER-001, TUB-PVC-020) o dejar que la IA lo genere.
  • Cero impacto en el historial: Como el sistema utiliza SQLite local y Google Sheets como respaldo vivo, puedes borrar y rehacer productos cuantas veces desees durante tus pruebas sin temor a dañar el sistema.
🔒 Respaldo Total en 1 Clic: Antes de comenzar tu inventario definitivo, puedes entrar a Ajustes > Centro de Respaldos en FerreMax y pulsar "Descargar Copia de Seguridad JSON" para tener un archivo seguro de tu base de datos en tu computadora.

📜 6. Código Fuente Completo del Conector Google Apps Script

Copia exactamente este bloque de código y pégalo en el editor de Apps Script según las instrucciones del Paso 3:

/**
 * ==============================================================================
 * CONECTOR OFICIAL FERREJADE, C.A. PARA GOOGLE DRIVE & GOOGLE SHEETS
 * Cuenta: ferrejadepzo@gmail.com
 * ==============================================================================
 * Este script convierte tu Google Sheet en un microservicio en la nube 100% gratuito.
 * Recibe los productos escaneados con la IA de la aplicación móvil de FerreJade,
 * guarda la información en la hoja de cálculo y almacena la foto física en una
 * carpeta de tu Google Drive, insertando el enlace directo a la imagen.
 *
 * 📋 INSTRUCCIONES DE INSTALACIÓN (Solo toma 2 minutos):
 * 1. Entra a tu Google Drive con tu correo (ferrejadepzo@gmail.com).
 * 2. Crea una Hoja de Cálculo de Google en blanco y nómbrala "FerreJade - Catálogo Maestro".
 * 3. En el menú superior de la hoja, haz clic en: Extensiones -> Apps Script.
 * 4. Borra todo el código que aparezca y pega este código completo.
 * 5. Haz clic en el disquete "Guardar" (Ctrl + S).
 * 6. Haz clic en el botón azul superior "Implementar" -> "Nueva implementación".
 * 7. En el icono de engranaje (⚙️), selecciona: "Aplicación web".
 * 8. Configura los campos:
 *    - Descripción: Conector FerreJade Catálogo IA
 *    - Ejecutar como: "Yo (ferrejadepzo@gmail.com)"
 *    - Quién tiene acceso: "Cualquier persona" (Anyone)
 * 9. Haz clic en "Implementar" y autoriza los permisos de Google.
 * 10. Copia la "URL de la aplicación web" generada (termina en /exec) y pégala
 *     en el sistema FerreJade en: Ajustes -> Conexión Google Drive / Sheets.
 * ==============================================================================
 */

function doPost(e) {
  try {
    var lock = LockService.getScriptLock();
    lock.waitLock(30000); // Evitar condiciones de carrera en escaneos simultáneos

    var payload = {};
    if (e.postData && e.postData.contents) {
      payload = JSON.parse(e.postData.contents);
    } else {
      payload = e.parameter || {};
    }

    var sheet = getOrCreateCatalogSheet();
    var folder = getOrCreateDriveFolder("FerreJade - Fotos de Productos");

    // Si viene un solo producto o una lista de productos
    var products = [];
    if (payload.products && Array.isArray(payload.products)) {
      products = payload.products;
    } else if (payload.product) {
      products = [payload.product];
    } else {
      products = [payload];
    }

    var savedCount = 0;
    var lastFileUrl = "";

    for (var i = 0; i < products.length; i++) {
      var p = products[i];
      if (!p.name && !p.sku) continue;

      var fileUrl = "";
      // Si el producto incluye la imagen en Base64 tomada por el escáner
      var rawImage = p.imageBase64 || p.imageUrl || "";
      if (rawImage && rawImage.indexOf("base64,") !== -1) {
        try {
          var cleanBase64 = rawImage.split("base64,")[1];
          var contentType = "image/jpeg";
          if (rawImage.indexOf("image/png") !== -1) contentType = "image/png";
          else if (rawImage.indexOf("image/webp") !== -1) contentType = "image/webp";

          var fileName = (p.sku || "PRODUCTO") + "_" + Utilities.formatDate(new Date(), "GMT-4", "yyyyMMdd_HHmmss") + ".jpg";
          var decoded = Utilities.base64Decode(cleanBase64);
          var blob = Utilities.newBlob(decoded, contentType, fileName);
          var file = folder.createFile(blob);
          file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
          fileUrl = file.getUrl();
          lastFileUrl = fileUrl;
        } catch (imgErr) {
          fileUrl = "Error al guardar imagen: " + imgErr.toString();
        }
      } else if (rawImage.indexOf("http") === 0) {
        fileUrl = rawImage;
      }

      var nowStr = Utilities.formatDate(new Date(), "GMT-4", "yyyy-MM-dd HH:mm:ss");
      var cost = parseFloat(p.cost || p.costUsd || 0);
      var priceUsd = parseFloat(p.price || p.priceUsd || 0);
      var margin = cost > 0 ? Math.round(((priceUsd - cost) / cost) * 100) + "%" : "N/A";
      var rateBcv = parseFloat(p.rateBcv || payload.rateBcv || 893.22);
      var priceBs = (priceUsd * rateBcv).toFixed(2);

      sheet.appendRow([
        nowStr,
        p.sku || "",
        p.barcode || "",
        p.name || "",
        p.brand || "Genérico",
        p.category || p.cat || "General",
        cost > 0 ? cost : "",
        margin,
        priceUsd > 0 ? priceUsd : "",
        priceBs,
        p.stock !== undefined ? p.stock : 1,
        p.unit || "UND",
        p.location || "Pasillo General",
        p.warranty || "N/A",
        p.specs || p.description || p.desc || "",
        fileUrl
      ]);
      savedCount++;
    }

    lock.releaseLock();

    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      message: "Se guardaron " + savedCount + " producto(s) en Google Sheets y Drive correctamente.",
      savedCount: savedCount,
      driveFileUrl: lastFileUrl
    })).setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

/**
 * Obtiene o inicializa la pestaña con encabezados corporativos FerreJade
 */
function getOrCreateCatalogSheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Catálogo FerreJade");
  if (!sheet) {
    sheet = ss.insertSheet("Catálogo FerreJade", 0);
  }

  // Si la hoja está vacía, colocar cabecera profesional con estilo FerreJade
  if (sheet.getLastRow() === 0) {
    var headers = [
      "Fecha y Hora",
      "SKU",
      "Código de Barras",
      "Nombre del Producto",
      "Marca",
      "Categoría",
      "Costo USD ($)",
      "Margen %",
      "Precio Venta USD ($)",
      "Precio Venta BCV (Bs)",
      "Stock Físico",
      "Unidad",
      "Ubicación Pasillo/Estante",
      "Garantía",
      "Especificaciones Técnicas",
      "Foto en Google Drive"
    ];
    sheet.appendRow(headers);

    var headerRange = sheet.getRange(1, 1, 1, headers.length);
    headerRange.setBackground("#003333"); // Verde Jade FerreJade
    headerRange.setFontColor("#CFB53B");  // Dorado FerreJade
    headerRange.setFontWeight("bold");
    headerRange.setFontSize(11);
    headerRange.setHorizontalAlignment("center");
    sheet.setFrozenRows(1);

    // Ajustar anchos iniciales
    sheet.setColumnWidth(1, 150); // Fecha
    sheet.setColumnWidth(2, 120); // SKU
    sheet.setColumnWidth(3, 130); // Barras
    sheet.setColumnWidth(4, 250); // Nombre
    sheet.setColumnWidth(5, 120); // Marca
    sheet.setColumnWidth(6, 150); // Categoría
    sheet.setColumnWidth(7, 100); // Costo
    sheet.setColumnWidth(8, 80);  // Margen
    sheet.setColumnWidth(9, 110); // Precio USD
    sheet.setColumnWidth(10, 120);// Precio Bs
    sheet.setColumnWidth(11, 90); // Stock
    sheet.setColumnWidth(12, 80); // Unidad
    sheet.setColumnWidth(13, 150);// Ubicación
    sheet.setColumnWidth(14, 100);// Garantía
    sheet.setColumnWidth(15, 260);// Specs
    sheet.setColumnWidth(16, 220);// Drive link
  }

  return sheet;
}

/**
 * Busca o crea la carpeta de fotos en Google Drive
 */
function getOrCreateDriveFolder(folderName) {
  var folders = DriveApp.getFoldersByName(folderName);
  if (folders.hasNext()) {
    return folders.next();
  }
  return DriveApp.createFolder(folderName);
}
